What WHITE checks

  • Whether the connection is encrypted (HTTPS, certificate, redirects, HSTS)
  • Browser protections such as Content-Security-Policy and clickjacking defences
  • Cookie protections (Secure, HttpOnly, SameSite)
  • Accidental exposure of error details, server versions and well-known sensitive files
  • Insecure forms, mixed content, robots.txt and sitemap entries
  • Optional, harmless input-handling indicators for sites you explicitly authorize

What WHITE does not do

  • It does not guarantee that a website is secure or detect every vulnerability.
  • It does not log in, guess passwords, submit forms or attempt exploitation.
  • It only inspects publicly reachable responses, with strict request and time limits.
  • It refuses private, local and cloud-internal network addresses.

Only scan websites you own or have written permission to assess.
